# Salón Boutique 2.2

Aplicación Android sin conexión para agenda, ingresos, servicios, clientas y copias de seguridad.

## Cambios de esta versión
- Eliminado el apartado de gastos, sus formularios y almacenamiento.
- Eliminado el menú de estadísticas. Se conservan los gráficos diarios y mensuales en inicio.
- Separación superior de 1,5 cm en las pantallas internas.
- Íconos adaptativos y tradicionales corregidos.
- Copias de seguridad compatibles con el formato anterior; al restaurar se ignoran los datos de funciones retiradas.

## Instalación
Compilar con el flujo de GitHub Actions o Android Studio. Actualizar sobre la aplicación existente mantiene los turnos y cobros. Se recomienda guardar una copia antes de actualizar.
